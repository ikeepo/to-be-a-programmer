# How to model JS as a language

### Bounded Contexts

| Bounded Context   | 核心问题         | 主要概念                                            |
| ----------------- | ------------ | ----------------------------------------------- |
| Language Syntax   | 代码如何被解析      | expression、statement、declaration、scope          |
| Runtime Execution | 一段代码如何被执行    | execution context、call stack、environment record |
| Value & Object    | 值和对象如何工作     | primitive、object、property、prototype             |
| Function          | 函数如何创建和调用    | closure、`this`、arguments、lexical environment    |
| Async Runtime     | 异步操作如何被调度    | job、task、microtask、event loop                   |
| Module            | 代码单元如何连接     | module record、binding、import/export             |
| Host Environment  | JS 与外部环境如何交互 | browser、DOM、Node.js、Web API                     |
