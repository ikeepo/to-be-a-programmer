# Computational Models
SICP does not catalogue every computational model. It selects a small number of foundational models and teaches how they can be constructed from simpler elements.

Its major progression is roughly:

$functional evaluation→data abstraction→state and mutation→concurrency→streams→interpreters$

sequential execution;
variables and mutable state;
function calls and call stacks;
objects and references;
asynchronous events;
database transactions.
